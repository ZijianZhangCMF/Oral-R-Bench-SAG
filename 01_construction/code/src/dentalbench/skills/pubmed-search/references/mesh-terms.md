## Query Construction Notes

- Always append `[MeSH Terms]` to each term.
- Use OR within a subspecialty to broaden coverage.
- When a subspecialty shares terms with another (e.g., "Burning Mouth Syndrome" appears in S1 and S10), the deduplication step in the main skill handles overlap.
- If a subspecialty query returns fewer than 50 results, progressively add broader terms from the "Broad terms" list.
- If a subspecialty query returns more than 200 results, prefer the specific terms and drop the broad terms.
